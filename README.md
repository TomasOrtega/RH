# RH

This repository contains the Lean project extracted from the archive accompanying Levent Alpöge’s Riemann Hypothesis note. [Original note (PDF)](https://alpo.ge/remark.pdf)

The Lean project is in [`extracted/lean/`](extracted/lean/). A summary is available in [`remark.md`](remark.md).

<details>
<summary>Verso</summary>

The [Verso proof archive](https://tomasortega.net/RH/) presents the Lean claims alongside English proof notes and their original Lean arguments. It includes written mathematical explanations for selected results and source translations for the remaining declarations. The annotated files are in [`verso/src/`](verso/src/) and CI publishes the site from the `verso` branch without elaborating the extracted proofs. [Build and annotation details](verso/README.md)

</details>
